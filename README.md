# TaskMarket — статичний прототип

Що це:
- Набір простих HTML/CSS/JS файлів — клікабельний прототип маркетплейсу для замовлень робіт.

Як запустити:
1. Помістити файли в одну теку.
2. Відкрити index.html в браузері.

Що видно в прототипі:
- Головна сторінка з переліком проєктів
- Сторінка проєкту з заявками і кнопкою "Подати заявку"
- Форма створення проєкту (додає проєкт у локальний масив)
- Профіль з портфоліо
- Простіший чат (симуляція)
